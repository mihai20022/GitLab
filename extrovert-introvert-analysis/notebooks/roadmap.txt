1. Impute or Drop

- <5%, impute or drop,
-  5-20%, impute preffered
- >20%, mostly drop, input only when the feature is important

2. Data Cleaning

In order to impute, the types of data should be considered:
numeric:
- Mean. Data is numeric. The distribution is normal. There are few outliers.
- Median. Data is numeric or ordinal. Distribution is skewed. There are outliers.
- Mode. Data is categorical. Ordinal categories. Binary columns.

***for numeric, the distribution should be checked. Normal -> mean, skewed -> median

In the personality_dataset, the distributions are skewed to the right. To preserve the consistency I will use median.
